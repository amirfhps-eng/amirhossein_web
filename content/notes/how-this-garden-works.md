The notes on this site are not finished articles. I publish them early and keep editing them, so each one carries a stage that says how far along it is.

## Growth stages

- **Seedling**: a rough first thought. It may be wrong or incomplete.
- **Budding**: taking shape. The main idea is there, but I'm still working on it.
- **Evergreen**: something I stand behind and keep up to date.

## How notes connect

Notes can link to each other, and every note lists the notes that link back to it. Tags group notes by topic. Both are built automatically from the files in the repository, so adding a note never needs any extra wiring.
